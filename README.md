# Win11 Launcher

一个 Windows 11 风格的软件启动台，把常用软件、文件、文件夹集中到一个美观的网格面板里，一键启动。

基于 **Python + PySide6（Qt）** 开发，支持亚克力磨砂背景、深浅色主题、拖拽整理、文件夹分组等功能。

---

## 功能特性

- **应用网格**：以卡片网格展示应用，图标自动从系统提取（支持高 DPI 高清图标）
- **分类管理**：内置「系统应用 / 办公软件 / 社交软件 / 影音视频 / 语言编程 / 我的游戏」等分类，可自由增删
- **文件夹分组**：把多个应用拖进一个文件夹，保持桌面整洁
- **拖拽整理**：拖动卡片即可调整顺序、移动到其他分类或文件夹
- **亚克力磨砂**：Win11 原生亚克力背景，卡片轻微透明，视觉通透
- **主题跟随**：支持浅色 / 深色 / 跟随系统，系统切换主题时程序自动同步
- **透明度调节**：窗口透明度可调，调整即时预览
- **全局快捷键**：默认 `Ctrl+Shift+L` 一键呼出 / 隐藏
- **托盘常驻**：关闭窗口最小化到任务栏，可从任务栏或托盘图标唤起（系统原生动画）
- **右键菜单**：应用卡片、文件夹、空白处均有右键菜单，支持启动、管理员启动、重命名、更换图标、移动分类、打开文件位置、属性等
- **新建文件**：空白处右键可直接新建文件夹、文本文档、Word / Excel / PowerPoint 文档
- **配置导入导出**：一键备份 / 恢复全部配置
- **开机自启**：可选开机自动启动

## 系统要求

- **操作系统**：Windows 11（Windows 10 亦可运行，但亚克力效果可能不完整）
- **运行环境**：绿色免安装版无需安装 Python，解压即用

## 安装与运行

### 方式一：绿色免安装版（推荐）

1. 前往本仓库的 **Releases** 页面，下载最新版 `Win11Launcher-vX.X.X-win64.zip`
2. 解压到任意目录（建议放在非系统盘，如 `D:\Win11Launcher`）
3. 双击 `Win11Launcher.exe` 即可运行

> 首次运行 Windows 可能提示「已保护你的电脑」，点击「更多信息」→「仍要运行」即可。

### 方式二：从源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/xuexiAI001/Win11Launcher.git
cd Win11Launcher

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main.py
```

## 使用说明

### 添加应用

- **空白处右键** → 「添加应用...」→ 选择 exe 文件
- 或直接把 exe / 快捷方式 **拖拽** 到窗口里

### 整理应用

| 操作 | 方式 |
|------|------|
| 调整顺序 | 拖动卡片到目标位置 |
| 移动到其他分类 | 右键卡片 → 「移动分类」→ 选择分类 |
| 移动到文件夹 | 右键卡片 → 「移动到文件夹」→ 选择文件夹 |
| 新建文件夹 | 右键卡片 → 「移动到文件夹」→ 「新建文件夹...」 |
| 移出文件夹 | 在文件夹内右键卡片 → 「移出文件夹」 |

### 应用卡片右键菜单

- 启动 / 管理员身份启动
- 移动分类 / 移动到文件夹
- 更换图标 / 重命名
- 删除应用 / 清空当前分类
- 打开文件位置 / 属性
- 设置

### 设置

右键空白处 → 「设置」，可配置：

- **启动快捷键**：默认 `Ctrl+Shift+L`
- **关闭时最小化到任务栏**（取消勾选则关闭即退出）
- **主题颜色**：浅色 / 深色 / 跟随系统（调整即时生效）
- **窗口透明度**：50% ~ 100%（调整即时生效）
- **开机自启动**
- **管理分类**：增删分类
- **导出 / 导入配置**
- **查看已扫描应用**：从开始菜单扫描应用，批量添加到分类

> 主题与透明度调整后**即时预览**，点击「保存设置」才会写入配置文件；点击「取消」或关闭窗口则恢复原值。

## 配置文件位置

所有配置与缓存保存在：

```
%APPDATA%\Win11Launcher\
├── launcher_config.json   # 应用列表、分类、主题、透明度等配置
├── launcher.log           # 运行日志（排查问题用）
└── icon_cache\            # 图标缓存
```

> 卸载时删除该目录即可彻底清除配置。

## 常见问题

**Q：任务栏图标显示为 Python 图标？**
A：绿色免安装版已修复此问题。若从源码运行，程序已通过 `AppUserModelID` 修正。

**Q：亚克力磨砂效果不明显？**
A：亚克力依赖 Windows 11 的 DWM 合成，Windows 10 或关闭了「透明效果」时可能不生效。可在「设置 → 个性化 → 颜色」中开启「透明效果」。

**Q：图标显示模糊？**
A：程序按屏幕 DPI 提取高清图标。若仍模糊，可在右键菜单中「更换图标」手动指定高清图标。

**Q：如何彻底卸载？**
A：删除程序目录，并删除 `%APPDATA%\Win11Launcher\` 配置目录即可。

## 技术栈

- **语言**：Python 3.14
- **GUI**：PySide6 6.11（Qt 6）
- **图标提取**：pywin32 / ctypes（SHGetImageList、ExtractIconExW 等）
- **图像处理**：Pillow + numpy
- **打包**：PyInstaller

```

│   ├── app_card.py      # 应用卡片

    └── app.ico          # 程序图标
```
